O
Salto.

Uma máquina para observar o passado.
Alguém resolveu atravessar.

A Dra. Katarina Usha desapareceu depois de usar a máquina do Projeto Terrassic. Você entra para buscá-la, o equipamento falha e o destino é a pré-história.

As anotações que ela deixou ajudam a entender o que aconteceu. Você decide se quer seguir os rastros dela ou simplesmente viver entre os dinossauros.

Como
jogar.

Terrassic é um mod autoral de dinossauros para Minecraft. Crie filhotes, explore com suas montarias e estude as espécies no Caderno de Campo.

Acompanhar no GitHub ↗Downloads públicos serão ligados aqui quando uma versão for publicada.
Minecraft Java 1.20.1

Instale o Fabric Loader e adicione Architectury API, GeckoLib e Fabric API nas versões compatíveis. Coloque o arquivo do Terrassic na pasta mods.

Antes
de jogar.

Qual Minecraft preciso ter?+

O alvo atual é Minecraft Java 1.20.1, com Fabric ou Forge. As dependências e os arquivos corretos devem ser conferidos na versão que você instalar.

A história é obrigatória?+

Não. Você pode construir, criar animais e explorar sem seguir a história. As anotações da Katarina são um caminho possível.

Esse elenco é a lista da próxima versão?+

O site mostra oito modelos do projeto. O conteúdo efetivamente disponível em cada lançamento será descrito nas notas da versão.

O que aparece no site é uma captura do Minecraft?+

Os modelos, texturas e animações vêm do mod. Aqui eles são renderizados no navegador para apresentação, com câmera e iluminação próprias.

O projeto
continua.

O Terrassic está em desenvolvimento. O código e o histórico das mudanças estão no GitHub.
